# 🍰 La Dolce Dinha

Site institucional da **La Dolce Dinha**, uma confeitaria artesanal especializada em doces personalizados, bolos decorados e encomendas sob medida.

---

## 📖 Sobre o Projeto

Este projeto tem como objetivo apresentar a marca **La Dolce Dinha**, seus produtos e serviços, além de facilitar o contato com clientes interessados em encomendas.

O site foi desenvolvido com foco em:
- Boa experiência do usuário
- Design moderno e responsivo
- Navegação simples e intuitiva

---

## ✨ Funcionalidades

- Apresentação da confeitaria
- Seção de produtos
- Área “Sobre”
- Links diretos para **WhatsApp** e **Instagram**
- Footer com informações e navegação adicional
- Layout responsivo
- Animações suaves para melhor experiência do usuário

---

## 🛠️ Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript  
- React  
- AOS (Animate On Scroll)  
- Vite
